
# Planto 🌱
### A little care, a greener life.

Planto is a simple iOS application designed to help users organize their plant care routines, set watering reminders, and track which plants still need attention.

## 🌿 Features

- **Plant Management:** Add, edit, and manage your plants.
- **Watering Reminders:** Set notifications to remind you when your plants need water.
- **Watering Tracker:** Mark plants as watered and keep track of their status.
- **Progress Tracking:** Monitor how many plants still need watering.
- **Personalized Watering:** Choose suitable watering amounts for each plant.
- **Dark Mode:** Enjoy a clean and user-friendly interface.

## 🌱 How It Works

1. Add a new plant to your collection.
2. Select its watering amount and preferences.
3. Set a watering reminder.
4. Mark the plant as watered when completed.
5. Track your overall watering progress.
6. Return the next day to continue your plant care routine.

## 🎯 Project Goal

Planto aims to make plant care simple, organized, and enjoyable by helping users build consistent watering habits through an intuitive iOS experience.
